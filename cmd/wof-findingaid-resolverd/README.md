## wof-findingaid-resolverd

Exposes a Who's On First finding aid resolver over HTTP.

```
$> wof-findingaid-resolverd -h
Exposes a Who's On First finding aid resolver over HTTP.
Usage:
	 wof-findingaid-resolverd [options]
Valid options are:

  -resolver-uri string
    	A registered whosonfirst/go-whosonfirst-findingaid/v2/resolver.Resolver URI.
  -server-uri string
    	A valid aaronland/go-http-server URI (default "http://localhost:8080")
```
