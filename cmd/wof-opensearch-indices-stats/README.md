## wof-opensearch-indices-stats

Retrieves OpenSearch index statistics.

```
$> wof-opensearch-indices-stats -h
Retrieves OpenSearch index statistics.
Usage:
	 wof-opensearch-indices-stats [options]
Valid options are:

  -opensearch-aws-credentials-uri string
    	...
  -opensearch-endpoint string
    	... (default "https://localhost:9200")
  -opensearch-insecure
    	...
  -opensearch-password string
    	...
  -opensearch-username string
    	...
```
