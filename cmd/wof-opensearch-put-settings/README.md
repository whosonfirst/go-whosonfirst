## wof-opensearch-put-settings

Updates the settings for an OpenSearch index.

```
$> wof-opensearch-put-settings -h
Updates the settings for an OpenSearch index.
Usage:
	 wof-opensearch-put-settings [options]
Valid options are:

  -opensearch-aws-credentials-uri string
    	...
  -opensearch-endpoint string
    	... (default "https://localhost:9200")
  -opensearch-index string
    	...
  -opensearch-insecure
    	...
  -opensearch-password string
    	...
  -opensearch-username string
    	...
  -settings string
    	...
```
