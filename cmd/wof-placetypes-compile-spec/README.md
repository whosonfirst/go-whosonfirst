## wof-placetypes-compile-spec

Compiles individual placetype definitions into a single specification.

```
$> wof-placetypes-compile-spec -h
Compiles individual placetype definitions into a single specification.
Usage:
	 wof-placetypes-compile-spec [options]
Valid options are:

  -iterator-source string
    	 (default "/usr/local/whosonfirst/whosonfirst-placetypes/placetypes")
  -iterator-uri string
    	 (default "directory://")
```
