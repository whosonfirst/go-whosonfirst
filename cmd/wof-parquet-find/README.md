## wof-parquet-find

Finds a Who's On First record by ID in a Parquet file.

```
$> wof-parquet-find -h
Finds a Who's On First record by ID in a Parquet file.
Usage:
	 wof-parquet-find [options]
Valid options are:

  -id int
    	The Who's On First ID to search for. (default -1)
  -parquet-uri string
    	 (default "The URI of the Parquet file to search for a record in.")
```
