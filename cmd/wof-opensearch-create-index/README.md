## wof-opensearch-create-index

Creates an OpenSearch index.

```
$> wof-opensearch-create-index -h
Creates an OpenSearch index.
Usage:
	 wof-opensearch-create-index [options]
Valid options are:

  -opensearch-aws-credentials-uri string
    	...
  -opensearch-endpoint string
    	... (default "https://localhost:9200")
  -opensearch-index string
    	...
  -opensearch-insecure
    	...
  -opensearch-password string
    	...
  -opensearch-username string
    	...
  -settings string
    	...
```
