## wof-findingaid-csv2sql

Loads archived finding aid CSV data into a SQL database.

```
$> wof-findingaid-csv2sql -h
Loads archived finding aid CSV data into a SQL database.
Usage:
	 wof-findingaid-csv2sql [options] path(N) path(N)
Valid options are:

  -database-uri string
    	... (default "sql://sqlite3?dsn=:memory:")
```
