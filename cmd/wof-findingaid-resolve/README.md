## wof-findingaid-resolve

Looks up the repository containing each requested Who's On First ID.

```
$> wof-findingaid-resolve -h
Resolves Who's On First IDs through a finding aid.
Usage:
	 wof-findingaid-resolve [options]
Valid options are:

  -id value
    	One or more IDs to resolve
  -resolver-uri string
    	A registered whosonfirst/go-whosonfirst-findingaid/v2/resolver.Resolver URI.
  -verbose
    	Enable verbose (debug) logging.
```
