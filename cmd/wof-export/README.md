## wof-export

Runs the command-line exporter for Who's On First records.

```
$> wof-export -h
Exports Who's On First records.
Usage:
	 wof-export [options] path(N) path(N)
Valid options are:

  -exporter-uri string
    	A valid whosonfirst/go-whosonfirst-export/v3.Exporter URI (default "whosonfirst://")
```
