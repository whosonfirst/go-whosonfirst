## wof-opensearch-list-indices

Lists OpenSearch indexes.

```
$> wof-opensearch-list-indices -h
Lists OpenSearch indexes.
Usage:
	 wof-opensearch-list-indices [options]
Valid options are:

  -opensearch-aws-credentials-uri string
    	...
  -opensearch-endpoint string
    	... (default "https://localhost:9200")
  -opensearch-insecure
    	...
  -opensearch-password string
    	...
  -opensearch-username string
    	...
  -raw
    	Display raw response JSON.
```
