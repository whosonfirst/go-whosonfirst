## wof-findingaid-create-dynamodb-tables

Creates the DynamoDB tables used by the Who's On First finding aid.

```
$> wof-findingaid-create-dynamodb-tables -h
Creates the DynamoDB tables used by the Who's On First finding aid.
Usage:
	 wof-findingaid-create-dynamodb-tables [options]
Valid options are:

  -billing-mode string
    	... (default "PAY_PER_REQUEST")
  -dynamodb-uri string
    	A valid aaronland/go-aws-session DSN
  -refresh
    	...
```
