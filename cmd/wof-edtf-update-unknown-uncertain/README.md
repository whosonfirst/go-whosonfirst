## wof-edtf-update-unknown-uncertain

Updates legacy open and unknown Extended Date/Time Format values and writes changed records to a configured writer.

```
$> wof-edtf-update-unknown-uncertain -h
Updates legacy open and unknown Extended Date/Time Format values and writes changed records to a configured writer.
Usage:
	 wof-edtf-update-unknown-uncertain [options] path(N) path(N)
Valid options are:

  -iterator-uri string
    	A valid whosonfirst/go-whosonfirst-iterate/v2 URI. Supported emitter URI schemes are:  (default "repo://")
  -writer-uri string
    	A valid whosonfirst/go-writer URI. (default "null://")
```
