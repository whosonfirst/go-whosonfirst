## wof-findingaid-csv2docstore

Loads archived finding aid CSV data into a Go Cloud document store.

```
$> wof-findingaid-csv2docstore -h
Loads archived finding aid CSV data into a Go Cloud document store.
Usage:
	 wof-findingaid-csv2docstore [options] path(N) path(N)
Valid options are:

  -docstore-uri string
    	...
```
