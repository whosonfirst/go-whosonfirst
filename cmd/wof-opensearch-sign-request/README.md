## wof-opensearch-sign-request

Signs an OpenSearch HTTP request using AWS credentials.

```
$> wof-opensearch-sign-request -h
Signs an OpenSearch HTTP request using AWS credentials.
Usage:
	 wof-opensearch-sign-request [options] path(N) path(N)
Valid options are:

  -credentials-uri string
    	
  -method string
    	 (default "GET")
  -uri string
    	
```
