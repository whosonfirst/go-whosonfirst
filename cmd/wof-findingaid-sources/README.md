## wof-findingaid-sources

Lists iterator sources supplied by a finding aid provider.

```
$> wof-findingaid-sources -h
Lists iterator sources supplied by a finding aid provider.
Usage:
	 wof-findingaid-sources [options]
Valid options are:

  -provider-uri string
    	... (default "github://whosonfirst-data")
  -uri-template string
    	...
```
