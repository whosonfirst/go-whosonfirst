## wof-properties-report

Generates a CSV report of Who's On First property definitions.

```
$> wof-properties-report -h
Generates a CSV report of Who's On First property definitions.
Usage:
	 wof-properties-report [options]
Valid options are:

  -properties string
    	The path to your whosonfirst-properties/properties directory
  -report string
    	The path to write your whosonfirst-properties report. Default is STDOUT.
```
