## wof-opensearch-put-mapping

Updates the field mapping for an OpenSearch index.

```
$> wof-opensearch-put-mapping -h
Updates the field mapping for an OpenSearch index.
Usage:
	 wof-opensearch-put-mapping [options]
Valid options are:

  -mapping string
    	...
  -opensearch-aws-credentials-uri string
    	...
  -opensearch-endpoint string
    	... (default "https://localhost:9200")
  -opensearch-index string
    	...
  -opensearch-insecure
    	...
  -opensearch-password string
    	...
  -opensearch-username string
    	...
```
