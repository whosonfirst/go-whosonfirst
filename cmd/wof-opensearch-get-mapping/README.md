## wof-opensearch-get-mapping

Retrieves the field mapping for an OpenSearch index.

```
$> wof-opensearch-get-mapping -h
Retrieves the field mapping for an OpenSearch index.
Usage:
	 wof-opensearch-get-mapping [options]
Valid options are:

  -opensearch-aws-credentials-uri string
    	...
  -opensearch-endpoint string
    	... (default "https://localhost:9200")
  -opensearch-index string
    	...
  -opensearch-insecure
    	...
  -opensearch-password string
    	...
  -opensearch-username string
    	...
```
